# 图的风格规范（STYLE SPEC）

> 这是**视觉契约**。改图前先读；改动须同步更新本文件。
> 实现位置：颜色与几何常量在 `src/chemfigstudio/core.py` 顶部，
> 各图的画布尺寸与坐标在 `src/chemfigstudio/figures.py`。

---

## 1. 字体

| 用途 | 粗细 | 字号（px） | 说明 |
|---|---|---|---|
| 图标题 | Bold | 31 | 左上角或居中 |
| 链上的 CH₃ / H₂ / OH | Bold | 27（下标 19） | 分子主体标签 |
| 系列图的行内标签 | Bold | 25（下标 17） | 每行分子缩小一点 |
| 总方程式 | Bold | 42（下标 27） | 反应图 |
| ΔH 数值 | Bold | 27 / 21 | 深红 |
| 底部说明 / 注释 | Regular | 19（下标 13） | 灰色 |
| 转角 C-H 计数注释 | Regular | 13–19 | 灰色 |

只用 **Arial**（`Arial.ttf` / `Arial Bold.ttf`）。
跨平台用 `CHEMFIG_FONT` / `CHEMFIG_FONT_BOLD` 指定。

## 2. 颜色

| 名称 | 值 | 用于 |
|---|---|---|
| `INK` | `#111827` | 键、正文、非氧原子 |
| `OXYGEN_RED` | `#D61F1F` | 氧原子与其孤对电子 |
| `DELTA_RED` | `#BE123C` | ΔH 数值 |
| `GREY` | `#788291` | 说明文字、注释 |
| `WHITE` | `#FFFFFF` | 背景（纯白，`RGB` 模式，不透明） |

**禁止**引入第五种颜色；需要区分层次时用同色不同字号/粗细。

## 3. 几何

| 项 | 值 | 含义 |
|---|---|---|
| `CHAIN_DX` | 92 px | 锯齿链水平步长 |
| `CHAIN_DY` | 50 px | 锯齿链垂直步长（系列图用 36，行距更紧） |
| `BOND_WIDTH` | 5 px | 键线宽 |
| 孤对电子 | 半径 3 px 的点 | 位置：`x = O_x + 9`，y 偏移 `-19`/`-11`（上方两点）、`+fs+5`/`+fs+13`（下方两点） |
| `CROP_MARGIN` | 26 px | 自动裁边后四周保留的白边 |

**链的画法**：顶点 `v[i] = (x0 + i·DX, ymid ± DY)`（i 为奇数向下、偶数向上），
相邻顶点连线；`CH₃` 标在首顶点左上；中间顶点在上方时标签写在上侧、下方时写下侧；
末顶点用一段短键连到 `OH` 的 O 上（**键必须连到 O，不能停在半路** —— 这是早期版本
被用户指出的真实 bug）。上下标基线偏移：下标 `+0.26 × 字号`，上标 `-0.34 × 字号`。

## 4. 画布尺寸（每次改都容易忘）

| 图 | 画布 | 裁边后典型尺寸 |
|---|---|---|
| `alcohol` | 1500 × 420 | ≈ 649 × 371 |
| `series` | 1800 × (130 + 168·n + 90) | ≈ 1164 × 892（n=5） |
| `reaction` | 2100 × 560 | ≈ 1435 × 531 |
| `chcount` | 1700 × 520 | ≈ 1145 × 511 |

**宁可画布大**：内容贴边会触发告警（`SaveReport.warnings`），不会静默出错。

## 5. 文本标记语法

| 写法 | 结果 |
|---|---|
| `H_{2}` | H 后面画小号 2（下标） |
| `g^{2}` | 上标 |
| `C_{2}H_{5}OH` | 化学式（`draw_formula` 会把 O 变红） |
| 其它字符 | 原样 |

**绝对禁止**直接在字符串里写 `₂`、`⁻¹`、`¹` 等 Unicode 上下标。

## 6. 单位与符号写法（面向 10 年级）

| 要写 | 写法 | 不要写 |
|---|---|---|
| 每克能量 | `kJ/g` | `kJ g⁻¹` |
| 每摩尔能量 | `kJ/mol` | `kJ mol⁻¹` |
| 摩尔质量 | `g/mol` | `g mol⁻¹` |
| 密度 | `g/mL` | `g mL⁻¹` |
| 比热容 | `J/g °C` | `J g⁻¹ °C⁻¹` |
| 键名 | `C-H`、`C-C`、`O-H`（**连字符**） | `C–H`（en dash）、`C—H`（em dash） |
| 燃烧焓标注 | `ΔH_{c} = -36.1 kJ/g` | `ΔH_c = -36.1 kJ g⁻¹` |
| 负号 | `-36.1` 或 `−36.1`（U+2212，Arial 有） | 不要用上标负号 |

## 7. 自检（内核自动做，别绕过）

1. **贴边检测**：内容触到画布边缘 → `warnings` 里出现"内容碰到画布边缘"。
2. **行重叠检测**（`series`）：相邻两行之间找不到全白行 → 告警。
3. **裁边**：按墨迹包围盒裁掉纯白边，保留 26 px。

任何 `warnings` 都必须传到用户面前（CLI 打印 / GUI 黄条 / 测试断言）。

## 8. 反面清单（做过并否决的）

| 别做 | 原因 |
|---|---|
| 用 RDKit / CDK 的 depict 出图 | 骨架式（端点式），不是课本示性式；且没有孤对电子 |
| 用 Unicode 上下标 | Arial 缺字 → `□` |
| 用 matplotlib 画分子 | 没有化学语义辅助；手动画键更直接（见 ADR-003） |
| 加边框/底色/阴影 | 与课本插图不符；Word 里也浪费墨水 |
| 键停在 O 前面 14 px（"看起来差不多"） | 放大后明显断开，被用户当场发现过 |
